#  Shopping List

##  Project Description
Shopping List is a simple web application developed using HTML, CSS, and JavaScript. This project helps users create and manage their shopping lists easily. Users can add items, mark items as completed, and remove items from the list.

##  Objectives
- To make shopping list management easy.
- To organize shopping items in one place.
- To provide a simple and user-friendly interface.

##  Features
- Add shopping items.
- Mark items as completed.
- Delete items from the list.
- Easy-to-use interface.
- Responsive design.

##  Technologies Used
- **HTML5** – Creates the structure of the application.
- **CSS3** – Adds styling and improves the appearance.
- **JavaScript** – Handles adding, completing, and deleting items.

##  How to Use
1. Open the Shopping List application.
2. Enter the name of a shopping item.
3. Click the Add button to add the item.
4. Mark an item as completed after purchasing it.
5. Delete items that are no longer needed.

##  Project Structure
- `index.html` – Main webpage.
- `style.css` – Styling for the webpage.
- `script.js` – JavaScript functionality.
- `README.md` – Project documentation.

##  Conclusion
The Shopping List project helps users manage their shopping tasks in a simple and organized way. It is a beginner-friendly project for learning HTML, CSS, and JavaScript.
